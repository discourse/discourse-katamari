# Katamari

A Discourse theme component that lets you roll a ball around the page and collect words.

## Install

Install from `https://github.com/discourse/discourse-katamari` and add the component to your theme.

## Play

Click an underlined **katamari** in a post or chat message, including links and oneboxes. Steer with your mouse, arrow keys, WASD, touch dragging, or device tilt. Reload to reset.
